## <div id="ai-platforms">AI Platforms 🏗️</div>

<details>
  <summary><strong>spiceai/spiceai</strong> — 3,076 ★</summary>

  **Description:** Portable, accelerated SQL query, search, and LLM-inference engine for data-grounded AI apps. Built in Rust on Apache DataFusion, Apache Ballista, Apache Arrow, and Apache Iceberg.

  **Link:** [https://github.com/spiceai/spiceai](https://github.com/spiceai/spiceai)

  **License:** Apache-2.0 (permissive)

  **What It Does:**
  - SQL query and search across 30+ data sources
  - LLM inference with OpenAI-compatible APIs
  - Real-time analytics node for operational databases
  - Distributed query with Apache Ballista
  - Vector search with Amazon S3 Vectors, DuckDB HNSW, and Elasticsearch kNN

  **Why This Matters:** Spice.ai is a complete data and AI platform that runs locally, in Docker, or in Kubernetes. It's fully open-source with no paywalls for core features.

  **Added:** 2026-09-06
</details>

<details>
  <summary><strong>aipoch/open-science</strong> — 3,635 ★</summary>

  **Description:** Open-source, local-first, model-agnostic AI research workbench with scientific agents, Python/R notebooks, data connectors, and reproducible research.

  **Link:** [https://github.com/aipoch/open-science](https://github.com/aipoch/open-science)

  **License:** Apache-2.0 (permissive)

  **What It Does:**
  - AI research workbench for macOS, Windows, and Linux
  - Scientific agents for automated research
  - Python/R notebooks with data connectors
  - Reproducible research workflows

  **Why This Matters:** Open Science provides a complete research environment for AI scientists, combining notebooks, agents, and data connectors in one platform.

  **Added:** 2026-09-06
</details>
