## <div id="datasets">Dataset Lists 📚</div>

<details>
  <summary><strong>mlabonne/llm-datasets</strong> — 4.8k ★</summary>

  **Description:** Curated list of datasets and tools for post-training LLMs. Covers general, math, science, code, instruction following, multilingual, agent & function calling, and preference datasets.

  **Link:** [https://github.com/mlabonne/llm-datasets](https://github.com/mlabonne/llm-datasets)

  **License:** MIT (permissive)

  **What's Inside:**
  - General instruction datasets (Nemotron-Cascade-2-SFT-Data, SYNTHETIC-2-SFT-verified, Dolci-Instruct-SFT)
  - Math datasets (MathX-5M, Nemotron-SFT-Math-v3, OpenThoughts3-1.2M, NuminaMath-CoT)
  - Science datasets (MegaScience, Nemotron-Science-v1)
  - Code datasets (CodeX-7M-Non-Thinking, Ling-Coder-SFT, Nemotron-SFT-Competitive-Programming-v2)
  - Instruction following datasets (Nemotron-SFT-Instruction-Following-Chat-v2, AutoIF-instruct-61k)
  - Multilingual datasets (Nemotron-SFT-Multilingual-v1, aya dataset, M2Lingual)
  - Agent & function calling datasets (AgentTrove, Nemotron-SFT-Agentic-v2, ToolMind)
  - Real conversations (WildChat-4.8M, lmsys-chat-1m)
  - Preference datasets (Skywork-Reward-Preference-80K-v0.2, ultrafeedback-binarized-preferences-cleaned, HelpSteer3)

  **Why This Matters:** This is one of the most comprehensive, well-organized lists of post-training datasets available. Maintained by Maxime Labonne (Head of Post-Training at Liquid AI), it's a must-have reference for anyone building LLMs.

  **Added:** 2026-09-06
</details>

<details>
  <summary><strong>mlabonne/llm-course</strong> — 82k+ ★</summary>

  **Description:** Course to get into Large Language Models (LLMs) with roadmaps and Colab notebooks.

  **Link:** [https://github.com/mlabonne/llm-course](https://github.com/mlabonne/llm-course)

  **License:** MIT (permissive)

  **What's Inside:**
  - LLM Fundamentals (Math, Python, Neural Networks, NLP)
  - LLM Scientist (Architecture, Pre-training, Post-training, SFT, Preference Alignment, Evaluation, Quantization, New Trends)
  - Resources and references

  **Why This Matters:** With over 82,000 stars, this is one of the most popular LLM learning resources on GitHub. It's a complete roadmap from fundamentals to advanced topics.

  **Added:** 2026-09-06
</details>

<details>
  <summary><strong>EleutherAI/llm-evaluation-harness</strong> — 5k+ ★</summary>

  **Description:** A unified framework to test generative language models on a large number of different evaluation tasks.

  **Link:** [https://github.com/EleutherAI/lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness)

  **License:** MIT (permissive)

  **What's Inside:**
  - 200+ tasks and benchmarks
  - Support for Hugging Face, vLLM, OpenAI, Anthropic, and more
  - Used for the Open LLM Leaderboard
  - Extensible and modular design

  **Why This Matters:** This is the gold standard for evaluating LLMs. It's what powers the Open LLM Leaderboard and is used by researchers worldwide.

  **Added:** 2026-09-06
</details>

<details>
  <summary><strong>lm-sys/FastChat</strong> — 30k+ ★</summary>

  **Description:** An open platform for training, serving, and evaluating large language model-based chatbots.

  **Link:** [https://github.com/lm-sys/FastChat](https://github.com/lm-sys/FastChat)

  **License:** Apache-2.0 (permissive)

  **What's Inside:**
  - Chatbot Arena data and code
  - Vicuna model weights and training code
  - Serving framework for LLMs
  - Evaluation tools

  **Why This Matters:** FastChat powers the Chatbot Arena, one of the most important evaluation platforms in the LLM community. The arena data is a goldmine for preference learning.

  **Added:** 2026-09-06
</details>
