## What This Is

A curated collection of open-source resources for LLM training, fine-tuning, and evaluation.

**No corporate bullshit. No HF. No Nvidia.**

## What We Index

| Section | What You'll Find |
|---|---|
| [DATASETS.md](DATASETS.md) | Curated datasets for pretraining, SFT, RLHF, DPO, and evaluation |

| [PAPERS.md](PAPERS.md) | Research papers with code links and dataset references |

| [PLATFORMS.md](PLATFORMS.md) | Larger infrastructure pieces and data/AI platforms |
| [AWESOME-LISTS.md](AWESOME-LISTS.md) | Curated lists of resources — a catalog of catalogs |
